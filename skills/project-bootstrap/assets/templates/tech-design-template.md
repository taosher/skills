## User Stories

> From the user (downstream) perspective, describe the typical usage scenarios of this solution. Examples:
>
> - For a product technical design, the perspective is the end user
>
> - For middleware, the perspective is developers and downstream systems
>
> - For a delivery tool, the perspective can be delivery engineers, on-site project managers, or even customers
>
